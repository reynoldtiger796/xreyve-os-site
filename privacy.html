Privacy Policy

This policy explains how XREYVE OS handles information in its current local-first website and in any future owner-authorized social analytics features. XREYVE OS is operated by the project's maintainer. We aim to minimize information collection and make account-related data use explicit.

1. What information is processed today

The public site and local mobile review workspace can process clip titles, descriptions, local video files chosen by a user, review notes, approvals, and browser-local storage. Local browser data is stored on the device and is not automatically synchronized to the XREYVE Windows runner. The owner-operated backend separately stores founder-provided post records, historical view snapshots, task IDs, system reports, and approved source metadata.

2. TikTok access and account permissions

No live TikTok account is connected to XREYVE OS at this time. If the official TikTok Login Kit / Display API connection is later approved and deployed, the system intends to request only relevant account identification and read-only video information scopes. With the account owner's consent, it would receive permitted profile identifiers, video IDs, titles, URLs, published dates, and available view, like, comment, and share counts. Account access can only be enabled after additional security review. We will update this policy before activating new data collection.

3. How information would be used

Data is used to organize authorized media review, display creator-owned performance reports, track content production decisions, prevent repeated work, and diagnose system failures. We do not sell personal information or use these records to buy engagement. Data is not used to publish TikTok videos automatically.

4. Storage and access

The existing historical analytics database and task queue are stored locally on the owner's Windows runner. Selected status reports are uploaded to private, time-limited GitHub Actions artifacts. Browser-local review files and decisions generally remain on the user's own device unless the user explicitly exports or shares them. Public website hosting may process routine technical logs under its own service policies. Future tokens will require a separately reviewed secure server-side storage design; they are not being collected by this app today.

5. Sharing and retention

Only technical providers used to host the public website or operate owner-controlled workflows may handle related infrastructure data under their own policies. Historical post records may be retained as necessary for owner-operated reporting, accuracy checks, and audit history; short-lived workflow artifacts have limited retention settings. Local browser storage remains until the user clears it or the app provides a deletion control.

6. Controls and requests

Users can remove their browser-local information through the application's available local data controls or browser settings. Account connection, revocation, and deletion tools for a future official TikTok integration will be documented before the integration is made available. To ask questions about access, correction, or deletion of operator-held information, use the maintainer's public GitHub profile, without posting sensitive data publicly.

7. Children and platform eligibility

Use of TikTok developer products and associated integrations is subject to the official eligibility and minimum-age rules that apply to those products. XREYVE OS does not provide a way to bypass those requirements.

8. Policy updates

We will update the published policy when new integrations materially change the data collected, how it is used, or how users can control it.
